# Лапа за лапой
Интерактивный семейный помощник по заботе о щенке той-пуделя. Русский интерфейс, мобильная и настольная вёрстка.

## Что внутри
30 тематических разделов исходного DOCX, 41 ссылка на источники, 7 настоящих фотографий (3 добавлены), 4 новых AI-иллюстрации и 20 исходных схем/пиктограмм. Пять видов интерактивных заданий, восемь значков за обучение, ежедневные списки до покупки и после появления щенка, родительские проверки, поездка, локальная карточка и журнал.

## Запуск локально
Нужен Python 3. Из папки комплекта:

```bash
python -m http.server 8080 --directory site
```

Открыть `http://localhost:8080/` в браузере. Не открывать `index.html` двойным щелчком для проверки офлайн-кэша: сервис-воркер требует HTTPS или localhost.

## Развёртывание
Папку `site` можно разместить на любом статическом HTTPS-хостинге. Сборки, npm, серверной базы и API-ключей не требуется. Все картинки и тексты внутри; внешние обращения нужны только при переходе по ссылкам источников.

Для Netlify: папка публикации `site`, команда сборки отсутствует. Для Vercel: Other / output directory `site`. Для GitHub Pages: публиковать только содержимое `site`, не весь репозиторий личных заметок.

## Данные и безопасность
Режимы «Дочке / Маме» — виды интерфейса, не авторизация. Записи сохраняются в localStorage, не синхронизируются между устройствами и не защищены отдельным паролем. Есть экспорт/импорт JSON с проверкой структуры. Не вводить секреты, адрес ребёнка и паспортные данные. Нет аналитики, сторонних скриптов, уведомлений или автоматической отправки контактов.

На общем домене RawGitHack личные карточка/журнал и свободный текст отключены; остаются знания, игры, чтение, списки и обезличенные родительские проверки. Полная локальная версия или индивидуальный домен поддерживает личные записи. Публичное демо содержит только исходную общую базу и незаполненные формы, не семейные персональные данные.

## Офлайн
В «Данные и настройки» нажать «Подготовить офлайн-доступ» с интернетом. Дождаться сообщения о завершении. Только после этого можно рассчитывать на сохранённые файлы. Внешние источники офлайн не открываются. При обновлении релиза поменять имя CACHE в `sw.js`.

## Точность и ограничения
Тексты 30 тематических разделов перенесены из `toy_poodle_illustrated_handbook.docx` программно. Печатная навигация заменена веб-навигацией. Игры и короткие карточки — явно обозначенные адаптации; они не дают медицинского заключения, готовности к покупке или реальной передачи ухода. Срочная помощь доступна сразу. Лекарства и корм не выдаются за игровые награды. Игровая ошибка не уменьшает накопленные значки.

Авторство фотографий и лицензии указаны в приложении. Лицензия CC BY-SA 4.0 сохранена у уменьшенной фотографии White Toy poodle. Имена авторов не означают одобрение приложения. AI-рисунки не выдаются за настоящие фотографии.

## Проверка
```bash
python -m pip install playwright
python -m playwright install --with-deps chromium
python qa/test_app.py
```
Тесты используют только вымышленные значения в изолированном браузерном профиле. Они не попадают в приложение.

`source-manifest.json` содержит SHA-256 исходной книги и сведения об адаптации. `state.md` — статус и инструкция продолжения работы.
